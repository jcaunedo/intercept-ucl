# Button

Triggers an action or event, such as submitting a form, opening a dialog, or moving to the next step.

## Variants

Buttons are `neutral` (dark) by default: use one per view for the main action. Use `brand` only where an action should carry the brand. Use `secondary`, `outline`, or `ghost` for supporting actions. Use `destructive` only for actions that delete or cannot be undone.

<Canvas of={ButtonStories.AllVariants} />

| Variant       | When to use                                         |
| ------------- | --------------------------------------------------- |
| `neutral`     | The default: the main action in a view              |
| `brand`       | An action that should carry the brand (rare). `default` is its deprecated alias |
| `secondary`   | A supporting action next to a primary button        |
| `destructive-secondary` | Stopping something without the weight of a solid red, e.g. End call |
| `outline`     | A neutral action that needs a visible boundary      |
| `ghost`       | Low-emphasis actions in toolbars and dense layouts  |
| `link`        | An action that should read like inline text         |
| `destructive` | Delete, remove, or other irreversible actions       |
| `success` | Accepting something that's waiting, e.g. Answer on an incoming call |

## Sizes

<Canvas of={ButtonStories.Sizes} />

Sizes follow the control size scale: `xs` 24px, `sm` 32px, `md` 36px (the default), `lg` 40px. Radii follow archielabs.ds: 8px at `xs`, 12px from `sm` up. UCL calls its 36px step `md` where shadcn says `default`. Use `md` unless a dense toolbar or inline action needs a smaller one. `xs` also shrinks the text and icon to 12px.

`icon-xs`, `icon-sm`, `icon-md` and `icon-lg` render a square button at each height. It has no visible label, so always set `aria-label`.

## With an icon

Place icons from `lucide-react` as children. The button sizes them to 16px (12px at `xs`; 18px in `icon-md` and 20px in `icon-lg`) unless the icon sets its own `size-*` class, and trims the padding on the icon's side, which it assumes is the left. Mark decorative icons with `aria-hidden="true"`.

## Disabled

A disabled button takes the `disabled` fill and a `foreground-subtle` label rather than fading; the outline keeps its fill with a lighter border.

<Canvas of={ButtonStories.DisabledVariants} />

## Loading

`loading` replaces the label with a spinner (screen readers still read the label) and ignores clicks until it's false. The button keeps its look, so it doesn't read as unavailable.

<Canvas of={ButtonStories.LoadingVariants} />

## As a link

Set `asChild` to render the button styles on the child element instead of a `<button>`. Use this for navigation, so the element stays a real link.

<Canvas of={ButtonStories.AsLink} />

## Accessibility

- Renders a native `<button>`, so keyboard and screen reader support work out of the box.
- The focus ring uses the `--ring` token and appears only on keyboard focus.
- Icon-only buttons need an `aria-label`.
- Use `asChild` with an `<a>` for navigation. Do not use a button with an `onClick` that changes the URL.
