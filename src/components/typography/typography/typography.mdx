# Typography

Text in Intercept's type scale. Choose the element for meaning with `as`, and the look with `size` and `weight`. It maps one to one to the archielabs.ds text styles: Figma's `lg/lg -semibold` is `size="lg" weight="semibold"`.

ℹ️ This page, the spec comment in `typography.tsx` and [Foundations → Typography](?path=/docs/foundations-typography--docs) together are the full typography spec. They change together.

## Fonts

**Figtree** for all interface text and **Roboto Mono** (`font-mono`) for code. Sizes up to `xl` use `font-sans` (Figma `font-family/bodytext`), and `2xl` and up use `font-display` (`font-family/headline`), as the Figma text styles bind them. Both are Figtree today. No letter spacing at any size. Apps load Figtree with weights 300–900 (see the [Introduction](?path=/docs/introduction--docs)).

## Sizes

`size` sets the font size and line height from the `--text-*` tokens.

| `size` | Font size / line height (px) | Figma text style |
| --- | --- | --- |
| `xs` | 12 / 18 | `xs/xs` |
| `sm` | 14 / 20 | `sm/sm` |
| `base` | 16 / 24 | `base/base` |
| `lg` | 18 / 28 | `lg/lg` |
| `xl` | 20 / 30 | `xl/xl` |
| `2xl` | 24 / 32 | `2xl/2xl` |
| `3xl` | 30 / 36 | `3xl/3xl` |
| `4xl` | 36 / 54 | `4xl/4xl` |
| `5xl` | 48 / 64 | `5xl/5xl` |
| `6xl` | 64 / 96 | `6xl/6xl` |
| `7xl` | 80 / 120 | `7xl/7xl` |

<Canvas of={TypographyStories.Sizes} />

Every Figma text style binds its size and line height to the `font-size/*` and `line-height/*` primitives, so these values match Figma exactly.

## Weights

The weights are Tailwind's defaults. They match Figma's `semantic` → `font-weight/*` variables in intercept mode, which all 55 text styles bind:

| `weight` | Utility | Value | Figma text style |
| --- | --- | --- | --- |
| `regular` | `font-normal` | 400 | `<size>/<size>` |
| `medium` | `font-medium` | 500 | `-medium` |
| `semibold` | `font-semibold` | 600 | `-semibold` |
| `bold` | `font-bold` | 700 | `-bold` |
| `black` | `font-black` | 900 | `-black` |

Typography has no `light` weight because Figma has no light text style; use `font-light` (300) directly when a design calls for it.

<Canvas of={TypographyStories.Weights} />

- Use `weight` (or the named `font-*` utilities). Never write `font-[500]`.
- ℹ️ The weights are per mode in Figma. Archie's modes use a lighter scale (350–650); intercept mode keeps the standard one. If intercept's values change, `theme.css` gets `--font-weight-*` tokens.

## Headings

`as="h1"`–`"h4"` without `size` or `weight` uses the heading defaults (`typographyHeadings`):

| Element | `size` / `weight` | Figma |
| --- | --- | --- |
| `h1` | `2xl` / `semibold` | `2xl/2xl -semibold`, "h1 / Modal Title" |
| `h2` | `xl` / `semibold` | `xl/xl -semibold`, "h2" |
| `h3` | `lg` / `semibold` | `lg/lg -semibold`, "h3" |
| `h4` | `base` / `semibold` | `base/base -semibold`, "h4" |

<Canvas of={TypographyStories.Headings} />

A page title is Figma's `3xl/3xl -bold` ("Page Title"). It's still the page's `h1`, one size larger and bold: `as='h1' size='3xl' weight='bold'`.

<Canvas of={TypographyStories.PageTitle} />

Pass `size` or `weight` only when a Figma frame binds something else. Pick the heading level for the page's structure, not for its look.

## Accessibility

- Use real heading elements (`as="h1"`–`"h6"`) for headings, in order, so screen readers can navigate the page by them.
- Don't use a heading element just for a big, bold look. Use `as="p"` with `size` and `weight` instead.
