# Intercept UCL

The React component library for Intercept. Components are built with React 19, Tailwind CSS 4, and Radix UI, and follow shadcn/ui conventions.

## Use UCL in an app

### 1. Point the app at GitHub Packages

UCL is published to GitHub Packages, not the public npm registry. Add an `.npmrc` at the app's root so npm fetches the `@jcaunedo` scope from there:

<Source
	language='ini'
	code={`@jcaunedo:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=\${NPM_TOKEN}`}
/>

`NPM_TOKEN` is a GitHub personal access token (classic) with the `read:packages` scope. GitHub Packages asks for a token even to install public packages.

- **Locally:** create the token at GitHub → Settings → Developer settings → Personal access tokens, and export it in your shell (`export NPM_TOKEN=…`). Never commit it: the `.npmrc` only names the variable.
- **In the app's CI and hosting:** add the same token as a secret named `NPM_TOKEN`.

### 2. Install

<Source language='bash' code={`npm install @jcaunedo/intercept-ucl`} />

`react` and `react-dom` 19 are peer dependencies: the app provides them, so it doesn't get two copies of React. Form components also need `react-hook-form`, `zod` and `@hookform/resolvers`, which are optional peer dependencies.

### 3. Import the styles

The package ships its design tokens in `@jcaunedo/intercept-ucl/styles`. Import them after Tailwind in the app's global stylesheet, and point Tailwind at the package so it generates the classes the components use.

<Source
	language='css'
	code={`@import "tailwindcss";
@import "@jcaunedo/intercept-ucl/styles";

@source "../node_modules/@jcaunedo/intercept-ucl/dist";`}
/>

Adjust the `@source` path so it's relative to the stylesheet. **Without it, component styles go missing without any error.**

### 4. Load the fonts

UCL declares the font tokens (`--font-sans`, `--font-mono` in `theme.css`) but doesn't load the webfonts. Each app loads the fonts those tokens name, for example with `next/font/google` or a Google Fonts `<link>`. Without them, text falls back to the system font.

### 5. Use a component

<Source
	language='tsx'
	code={`import { Button } from "@jcaunedo/intercept-ucl";

export function Example() {
  return <Button>Continue</Button>;
}`}
/>

### Dark mode

Add the `dark` class to a parent element, usually `<html>`, to switch every token to its dark value.

### Merging classes

Every component accepts `className`. Use the exported `cn()` helper to merge classes in your own components. It resolves Tailwind conflicts, so the last class wins.

<Source
	language='tsx'
	code={`import { cn } from "@jcaunedo/intercept-ucl";

<div className={cn("p-4", isActive && "bg-accent")} />`}
/>
