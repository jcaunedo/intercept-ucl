# Colors

Every color in UCL is a token in `src/styles/theme.css`, synced from the archielabs.ds Figma file: the `intercept` mode
in `:root` and `intercept-dark` in `.dark`. Use tokens through their Tailwind utilities, never as raw values: a token
named `background-subtle` is `bg-background-subtle`, `text-background-subtle`, `border-background-subtle`, and so on.

## How tokens are named

- **Two tiers.** Primitive ramps (`gray`, `catalina`, `elf`, `corn` and the status ramps) hold the raw colors.
  Semantic tokens (`primary`, `foreground`, `border`, `brand-subtle`) point at them and name what the color does.
  Components use semantic tokens only; the primitives aren't Tailwind colors.
- **shadcn roles first.** `background`, `foreground`, `card`, `popover`, `primary`, `secondary`, `muted`, `accent`,
  `destructive`, `border`, `input` and `ring` keep shadcn's names, so shadcn components work unchanged.
- **Tones come in steps.** Each tone (`brand`, `tone-accent`, `emphasis`, `neutral`, `info`, `success`, `warning`,
  `destructive`) has `-subtle`, `-muted` and, for most, `-defined` steps, plus a `-foreground` for text on it.
- **`accent` isn't the accent color.** shadcn's `accent` is the hover surface. Figma's accent tone (elf) is
  `tone-accent`.
- **Pair every surface with its foreground** (`bg-primary text-primary-foreground`), so text keeps its contrast in
  both modes.

The tables are generated from `theme.css`: a token added there appears here with no doc change. Each value shows the
primitive it points to in that mode and the color it renders as. The Figma variable behind every token is in DESIGN.md
→ "Figma → theme.css token map".

## Chart colors

`chart-1` to `chart-5` tell data series apart, nothing else. They use Intercept's brand hues (catalina, elf, corn) plus
plum and violet, and avoid red, orange and green, which mean critical, caution and normal in a clinical interface.

- Assign them in order and keep a series on its color when filters change. Past five series, group into "Other".
- Show clinical states (out-of-range values, alerts, thresholds) with the status tokens plus an icon or label, never
  with a chart color. Reference ranges and baselines are neutral gray.
- Never rely on color alone: add a legend, direct labels where they fit, and a table view.

⚠️ **Constraint:** `chart-5` (gold) is close to `warning`. Use it only for a fifth series, and label it directly.

See DESIGN.md → "Chart colors" for the validation behind the order.
