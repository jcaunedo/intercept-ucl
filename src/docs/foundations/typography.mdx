# Typography

UCL sets text with the `Typography` component, whose `size` and `weight` props map to the type tokens. Use `Typography`
(or its `typographyVariants` classes) rather than raw `text-*`/`font-*` utilities, so text stays on the scale. See
[Typography → Docs](?path=/docs/typography-typography--docs) for its props, and
[Guidelines → Typography](?path=/docs/guidelines-typography--docs) for how to choose sizes and headings.

Every table on this page is generated: Tailwind's default type tokens first, then the tokens `src/styles/theme.css`
defines on top, synced from the archielabs.ds text styles in `intercept` mode. Sizes `8xl` and `9xl` and the extra
weights are Tailwind defaults with no Figma text style.

## Font

There are two family tokens, both **Figtree** in archielabs.ds `intercept` mode: sizes up to `xl` use `font-sans`
(Figma's `font-family/bodytext`), and `2xl` and larger use `font-display` (`font-family/headline`). Code uses
`font-mono`, **Roboto Mono** (`font-family/code`).

<FontFamilies css={typeCss} />

ℹ️ `theme.css` declares the font tokens but doesn't load the webfonts. Storybook loads them in
`.storybook/preview-head.html`; apps load them in their document `<head>` (see the
[Introduction](?path=/docs/introduction--docs)).

## Headings

Choose the heading level with `as`, for document structure and screen readers. `h1`–`h4` without `size`/`weight`
render their definition (`typographyHeadings`), shown here as rendered:

<HeadingDefinitions />

```tsx
<Typography as='h1'>Projects</Typography>
```

`h1` is also the page and modal title. Pass `size` or `weight` only when a specific Figma frame binds something else;
that value wins for that instance.

ℹ️ Each heading is tagged in its Figma text style: `h1` is `2xl/2xl -semibold` ("h1 / Modal Title"), `h2` `xl`, `h3`
`lg` and `h4` `base`, all semibold. A page title is `3xl/3xl -bold` ("Page Title"): write
`<Typography as='h1' size='3xl' weight='bold'>` (DESIGN.md "Heading element → Typography pairing").

## Type scale

Each size sets both font size and line height. The `Typography` column shows what the `size` prop adds beyond the base:
the display font from `2xl` up. There's no letter spacing at any size. Sizes marked "Not in `Typography`" exist as tokens but
aren't a `Typography` size.

<TypeScale css={typeCss} />

## Weights

`Typography` offers `regular`, `medium`, `semibold`, `bold`, and `black`; the other weights are tokens only.
