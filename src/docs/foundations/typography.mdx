# Typography

UCL sets text with the `Typography` component, whose `size` and `weight` props map to the type tokens. Use `Typography`
(or its `typographyVariants` classes) rather than raw `text-*`/`font-*` utilities, so text stays on the scale. See
[Typography → Docs](?path=/docs/typography-typography--docs) for its props, and
[Guidelines → Typography](?path=/docs/guidelines-typography--docs) for how to choose sizes and headings.

Every table on this page is generated: Tailwind's default type tokens first, then any token `src/styles/theme.css`
defines on top. When the `intercept` text styles are synced from archielabs.ds, their values replace the defaults here
automatically.

## Font

There are two family tokens: sizes up to `lg` use `font-sans` (body), and `xl` and larger use `font-display`
(headlines). `--font-display` points at `--font-sans` until the design system defines a headline family.

<FontFamilies css={typeCss} />

ℹ️ The font tokens are declared but no webfont is loaded yet, so text renders in the system font stack. Once Intercept's
family is set, Storybook loads it in `globals.css` and apps load it themselves (see the
[Introduction](?path=/docs/introduction--docs)).

## Headings

Choose the heading level with `as`, for document structure and screen readers. `h1`–`h4` without `size`/`weight`
render their definition (`typographyHeadings`), shown here as rendered:

<HeadingDefinitions />

```tsx
<Typography as='h1'>Projects</Typography>
```

`h1` is also the page and modal title. Pass `size` or `weight` only when a specific Figma frame binds something else;
that value wins for that instance.

⚠️ **Decision needed:** these heading definitions are the template defaults. Confirm them against the `intercept` text
styles in Figma during the first design system sync (DESIGN.md "Heading element → `Typography` `size` pairing").

## Type scale

Each size sets both font size and line height. The `Typography` column shows what the `size` prop adds beyond the base:
the display font from `xl` up and 1% tracking at `lg` and `xl`. Sizes marked "Not in `Typography`" exist as tokens but
aren't a `Typography` size.

<TypeScale css={typeCss} />

## Weights

`Typography` offers `regular`, `medium`, `semibold`, `bold`, and `black`; the other weights are tokens only.
