# Typography

Type is set with Tailwind's font and text-size tokens. The `Typography` component maps them to one scale, so use it for text instead of writing `text-*` and `font-*` classes by hand. Its props are on the [Typography component page](?path=/docs/typography-typography--docs).

## Font families

| Token            | Utility        | Used for                                         |
| ---------------- | -------------- | ------------------------------------------------ |
| `--font-sans`    | `font-sans`    | Body text and sizes up to `lg`                   |
| `--font-display` | `font-display` | Sizes `xl` and up. Defaults to `--font-sans`     |
| `--font-mono`    | `font-mono`    | Code and tabular identifiers                     |

`--font-display` is mapped in `src/styles/theme.css`. Point it at Intercept's headline family when the design system defines one. UCL declares the font tokens but doesn't load the webfonts: each app loads them (see Introduction → "Load the fonts").

<Unstyled>
<div style={{ display: "grid", gap: "0.75rem", margin: "1.5rem 0" }}>
	<div className='font-sans text-2xl'>Sans: The quick brown fox jumps over the lazy dog</div>
	<div className='font-display text-2xl'>Display: The quick brown fox jumps over the lazy dog</div>
	<div className='font-mono text-lg'>Mono: const answer = 42;</div>
</div>
</Unstyled>

## Type scale

`size` sets the font size and line height together. Sizes up to `lg` use `font-sans`, and `xl` and up use `font-display`.

<Unstyled>
<div style={{ display: "grid", gap: "0.5rem", margin: "1.5rem 0" }}>
	{["7xl", "6xl", "5xl", "4xl", "3xl", "2xl", "xl", "lg", "base", "sm", "xs"].map((size) => (
		<div
			key={size}
			style={{ display: "grid", gridTemplateColumns: "4rem 1fr", alignItems: "baseline", gap: "1rem" }}
		>
			<code>{size}</code>
			<Typography size={size} style={{ whiteSpace: "nowrap", overflow: "hidden", textOverflow: "ellipsis" }}>
				Almost before we knew it, we had left the ground
			</Typography>
		</div>
	))}
</div>
</Unstyled>

## Headings

`h1`–`h4` have a default size and weight, so the element alone sets the look. `h1` is also the page and modal title.

| Element | `size` / `weight`   | Font           |
| ------- | ------------------- | -------------- |
| `h1`    | `2xl` / `semibold`  | `font-display` |
| `h2`    | `xl` / `semibold`   | `font-display` |
| `h3`    | `lg` / `semibold`   | `font-sans`    |
| `h4`    | `base` / `semibold` | `font-sans`    |

<Source
	language='tsx'
	code={`<Typography as="h1">Projects</Typography>
<Typography as="h2">Recent activity</Typography>`}
/>

Choose the heading element by document structure, not by how big it should look. When a design needs a different size, keep the element and override `size`.
